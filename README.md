# Linrol's Homebrew Tap

Official Homebrew tap for Linrol's macOS applications.

## Installation

### SwaprTrans
In-place text translation and rewrite tool for macOS (Native Swift, <2MB, on-device translation).

```bash
brew install linrol/tap/swapr-trans
```

Or tap first:
```bash
brew tap linrol/tap
brew install --cask swapr-trans
```

---

### Katib
Real-time bidirectional meeting speech transcription and live captions for macOS (SenseVoice on-device neural engine, ScreenCaptureKit).

```bash
brew install linrol/tap/katib
```

Or tap first:
```bash
brew tap linrol/tap
brew install --cask katib
```

---

## Update

```bash
brew upgrade swapr-trans
brew upgrade katib
```
